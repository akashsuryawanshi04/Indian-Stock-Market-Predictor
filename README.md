# AI-Based Indian Stock Market Prediction Platform

A complete end-to-end Machine Learning project that predicts Indian NSE stock prices using Random Forest Regression.

## Features

- Real-time NSE stock data
- Random Forest Regression model
- Technical indicators
- Interactive Streamlit dashboard
- Buy/Sell recommendation system
- Plotly charts

## Installation

```bash
pip install -r requirements.txt
```

## Run Model Training

```bash
python train_model.py
```

## Run Streamlit App

```bash
streamlit run app/app.py
```

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Plotly
- yfinance
